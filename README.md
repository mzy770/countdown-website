# AETHER · 临界

透明全息投影倒计时与常驻待办。React 19、Tailwind CSS 4、Framer Motion、Three.js、Vite。

## 开发与发布

```sh
npm ci --cache /workspace/.npm-cache
npm run dev
npm run build
```

源码位于 `source/`。构建把生产入口与资源复制到仓库根目录的 `index.html` 和 `assets/`，兼容 GitHub Pages 的 `main / (root)` 设置。提交构建结果与源码后触发 Pages 更新。资源使用相对路径，支持 `/countdown-website/` 子目录。不要手工编辑生成的生产文件。

## 当前设计

- 巨大天数为视觉中心，时分秒在下方。Orbitron 字体随资源自托管。
- SVG 数字用稳定冰蓝轮廓、半透明冷白填充、细扫描纹和内部结构构成；光纹缓慢经过内部，极淡轮廓残影形成投影层次。秒数切换以 250ms 局部重组过渡。
- 透明曲面通过弧形边缘与断续刻度呈现，移除实体玻璃厚边、磨砂背景和外围雷达及随机坐标。
- 数字、日期和曲面以不同幅度响应鼠标位置。触屏和减少动态效果模式下不启用视差。
- 光轨减量并降低存在感，下方短光源与渐隐光束暗示投射来源。
- 待办常驻显示，终端式输入与菱形完成按钮；完成时消散并触发 3D 立方体能量扩散，柔和音效默认关闭。

## 数据与兼容

数据只保存在当前浏览器 localStorage，兼容第一版 `aether-v1` 数据。日期按设备本地时区计算，到期后归零。无需账号或后端。WebGL 不可用时仍显示 CSS/SVG 投影与所有功能。系统减少动态效果设置可在页面打开时动态生效，停止装饰运动、光纹和粒子爆散。

## 考纲学习模块

依据用户提供的六张考纲截图，拆分为 265 项：力学 61、热学 12、电磁学 38、光学 45、原子物理 43、量子力学 66。模块数据位于 `source/syllabus.js`，按截图中的章节及细分知识点组织，部分紧密相关的概念合为一个学习单元。复习日程建议、分数线、参考书目未作为考点导入；未补写截图以外的考纲内容。

新版首次在浏览器打开时，自动向已有待办追加模块，不改变已有日期或自定义事项。`syllabusVersion` 标记防止反复导入；`completedModules` 记录已完成模块，刷新或重新构建后不会恢复已完成项。完成进度、学科筛选和章节/考点搜索均在主界面显示。学习记录依旧仅保存于当前浏览器，换设备不会同步；清除站点数据后会重新初始化。更新网站后需刷新页面才能导入，并不直接修改用户已经打开的浏览器数据。
